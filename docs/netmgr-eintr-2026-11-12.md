# Падение Android при включении Wi-Fi: 12 ноября 2026

Во время сравнения сна владелец сообщил о падении при включении Wi-Fi. В 09:44:24 `system_server` завершился с SIGABRT внутри старой `/vendor/lib/libnetmgr.so`. Ядро не перезапускалось. Этот замер сна признан недействительным: изменились Wi-Fi и состояние Android.

## Что установлено

За три секунды до падения зарегистрирован ANR SystemUI. Главный поток интерфейса ждал `WifiManager.getSupportedFeatures()`, а Wi-Fi — завершения `IWifiChip.configureChip()`. Это объясняет зависший интерфейс, но само по себе ещё не доказывает причину задержки Wi-Fi HAL.

Стек аварии и сохранённые регистры слушателя подтверждают другую, конкретную ошибку: отрицательный результат `select()` попадает в безусловную аварийную остановку процесса. В том числе так обрабатывается `EINTR`: штатное прерывание ожидания сигналом. Исторический `errno` из пользовательского падения не сохранился; связь именно этого падения с EINTR остаётся обоснованной гипотезой. Однако дефект воспроизведён отдельно на самом планшете.

В более новом [исходнике Qualcomm netmgr](https://github.com/bcyj/android_tools_leeco_msm8996/blob/master/data/netmgr/src/netmgr_netlink.c), в `netmgr_nl_socklthrd_main`, EINTR уже обрабатывается повторением ожидания. Это справочный исходник другой версии, а не исходник всей установленной библиотеки.

## Узкая бинарная правка

- Только при отрицательном результате `select()` вызывается `__errno()`.
- При `errno == EINTR` слушатель возвращается к ожиданию.
- Другие ошибки сохраняют исходную аварийную обработку.
- Положительный и нулевой результаты сохраняют исходные переходы и флаги сравнения.
- Код добавлен в проверенный нулевой промежуток файла; расширен размер существующего исполняемого ELF-сегмента. Размер файла не изменён.
- Дополнительного сервиса, опроса или фонового процесса нет.

Точный оригинал: `f74b5603007fa892389560ea381588684ed6d0b9cb9032d9098203e7f337b928`.

Исправленный файл: `b0e7c0f6932f4829c83bdc0719ae67dd7d50386b75dda41b43272c00d8a3528f`.

Размер обоих: 42 492 байта. Другие версии, включая Android 13, не проверены и этим манифестом не принимаются.

## Проверка

1. Эмуляция реальных ARM Thumb инструкций: 140 случаев — EINTR, 133 остальных значения errno, нулевой и положительные результаты. Проверены сохранение регистров и флаг нулевого результата.
2. Отдельный процесс на планшете загружает частную копию библиотеки, создаёт pipe и запускает экспортированный слушатель. Он не обращается к модему или Wi-Fi. Оригинал после прерывания сигнала выдаёт `select failed!` и доходит до SIGABRT с тем же смещением `0x2b9b`.
3. Исправленная копия выдерживает 20 направленных прерываний, обрабатывает два сообщения pipe и штатно завершает поток. Два успешных запуска до установки.
4. Установка выполнена атомарной заменой файла с сохранением владельца, прав и SELinux label. Исходник и метаданные сохранены на ПК. Android перезапущен без перезагрузки ядра. Хеш и чистое состояние системной файловой системы подтверждены; раздел возвращён в режим чтения.

Сбои первых вариантов собственного изолированного теста сохранены в приватных логах и не считаются новыми сбоями Android. Системная установка выполнена только после успешной проверки исправленного варианта.

Это исправление воспроизводимого дефекта, но ещё не доказательство устранения всех возможных зависаний при включении Wi-Fi. Проверка настоящих переключений и длительное наблюдение нужны отдельно.

Обновлённый приватный комплект от 12 ноября содержит эту библиотеку вместе с предыдущими ремонтами. Проверка на уже исправленном планшете показывает 0 необходимых изменений. Библиотека установлена отдельно; совокупный recovery installer на чистом втором устройстве по-прежнему не проверен.

## Повторение и откат

Полные проприетарные библиотеки и личные журналы в репозиторий не включены. Получите файл из своей точно такой же прошивки, затем:

```text
python tools/patch_rom.py --manifest patches/2026-11-12-netmgr.json netmgr-eintr ORIGINAL_LIBNETMGR.so FIXED_LIBNETMGR.so
python tools/patch_rom.py --manifest patches/2026-11-12-netmgr.json --reverse netmgr-eintr FIXED_LIBNETMGR.so RESTORED_LIBNETMGR.so
```

Для эмуляции требуется пакет Python `unicorn`:

```text
python tools/netmgr-eintr/test_emulation.py FIXED_LIBNETMGR.so
```

Исходник изолированного теста находится в `tools/netmgr-eintr/`. Он использует ARM32 ABI Android 10; тестовое прерывание направляется только своему потоку. Это диагностический инструмент, не приложение для постоянной установки.

При ручной установке нужны резервная копия, атомарная замена `/vendor/lib/libnetmgr.so`, `root:root`, режим `0644`, label `u:object_r:vendor_file:s0` и перезапуск использующего библиотеку Android. Для отката возвращается сохранённый оригинал с теми же метаданными. Нельзя перезаписывать содержимое активно используемого файла на месте.
