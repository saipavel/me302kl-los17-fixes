# Secure AVC: увеличение MFC heap позволило запустить декодер

12 ноября 2026. После увеличения MFC heap с 8192 до 270336 байт защищённый AVC прошёл create/configure/start/stop/release на SurfaceControl. Это первый успешный полный lifecycle; кадры, MediaCrypto и DRM playback ещё не проверены.

## Изменение ядра

База — рабочее ядро с watchdog repair, boot SHA-256 `d2cacd5c413e13a17489b7161062f2e9edbe53c3044c33368380d66df80b8cfc`. В распакованном ядре изменено только одно поле: `0xc12de87c`, размер MFC heap `0x2000` → `0x42000`. Поле находится в записи type=6, id=12, name=mfc. Правка Wi-Fi сохранена; ramdisk и остальная часть boot image не менялись, boot ID пересчитан. Полный образ остаётся приватным.

Дизассемблирование текущего `apq8064_calculate_reserve_sizes` подтверждает округление верхней фиксированной области до 1 MiB при резервировании. Оба размера укладываются в одно округлённое резервирование. Это не запрос дополнительной оперативной памяти и не перенос начала соседних heaps. После загрузки debugfs подтвердил heap `0xa5c00000..0xa5c41fff`, размер `0x42000`.

Кандидат собран с проверкой исходного SHA-256, обратной распаковкой и сравнением kernel payload (изменился один байт), проверкой сохранения ramdisk. Boot записан через TWRP только в boot-раздел с проверкой SHA-256 после записи. Первый USB-transfer в recovery оборвался до записи; повторная попытка прошла. Кандидат SHA-256 `9f23948d01aead153fef24423a05fae1973419b2028fa919d5c7cd27313c87d5`.

## Тест

Временно подключены официальный согласованный VIDC-комплект и ранее проверенный input-port patch. Helper создал secure compositor Surface и сообщил:

```text
COMPOSITOR_SURFACE_OK
CREATE_OK ms=20355
CONFIGURE_OK
START_OK
STOP_OK
RELEASE_OK ms=40863
```

PIL refcount после теста 0. Временные library/firmware mounts сняты, исходные SHA-256 проверены. Задержки старых Binder-вызовов остались. Успех относится к одной сессии 320×240 без подачи кадров; другие разрешения, повторные сессии, лицензии и воспроизведение не доказаны. После измерения рабочее ядро восстановлено через TWRP, SHA-256 boot-раздела повторно проверен. Readback зафиксирован в evidence.
